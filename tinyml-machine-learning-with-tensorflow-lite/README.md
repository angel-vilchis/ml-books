# TinyML

Original implementations and experiments inspired by:

> Pete Warden and Daniel Situnayake, *TinyML: Machine Learning with TensorFlow
> Lite on Arduino and Ultra-Low-Power Microcontrollers*.

## Planned work

- Recreate selected concepts with original code and notes.
- Run small TensorFlow Lite models on supported microcontroller hardware.
- Document hardware, toolchain versions, measurements, and observations for
  each experiment.

This repository does not reproduce the book's prose, figures, datasets, or
exercise solutions.
